# AutoStream AI Agent 🚗🤖

AutoStream is a **conversational AI agent** built as part of an internship assessment for **ServiceHive**. It is designed to assist automotive customers by understanding their intent, maintaining conversation context, retrieving relevant information, and qualifying potential leads.

### ✨ Features

* 🤖 Natural multi-turn conversations
* 🧠 Intent detection and conversational memory
* 📚 RAG-based knowledge retrieval
* 🎯 Lead qualification and information collection
* 🔄 Stateful agent workflow
* 🔌 API-ready architecture

### 🏗️ Workflow

```text
User Query
    ↓
Intent Detection
    ↓
Memory + Context
    ↓
Knowledge Retrieval (RAG)
    ↓
AI Agent
    ↓
Response / Lead Capture
```

### 🛠️ Tech Stack

**Python • LLM • RAG • Vector Search • AI Agents • REST API • Git**

### 🎯 Objective

The project demonstrates how an AI agent can move beyond simple chatbot responses and handle **context-aware conversations and real-world customer workflows**.

Built for the **ServiceHive internship assessment**.
